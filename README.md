# Homework

Interactive homework pages for parents and kids, published with GitHub Pages.

- `reading-4-6/` – reading sheets 4–6 (© Tali Shneidman, used for home practice)
- `writing-4-6/` – cursive writing practice for the same week (letters, words, sentences)

Navigation rules: every exercise gets its own folder and page, listed on the home page under its week.
Each page has a "🏠 כל שיעורי הבית" link back home at the top, a subtitle saying "תרגיל N מתוך M",
and a link at the bottom to the other exercise(s) of the same week.
